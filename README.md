# Caribbean Climate Demand

Causal/econometric study of hourly temperature, humidity, and solar-radiation exposure and residential electricity consumption in the Colombian Caribbean.

## Repository areas

- `docs/` - research design, decisions, protocols, and documentation.
- `data/` - data dictionaries, manifests, schemas, and release metadata; raw/private data stay outside Git.
- `src/` - reusable source code.
- `analysis/` - analysis scripts/notebooks/do-files.
- `results/` - reproducible result metadata and selected publishable outputs.
- `manuscript/` - paper source.
- `references/` - bibliographic files and literature metadata.
- `tests/` - code/data validation tests where applicable.

Collaborators may use Git, Stata, R, Python, Julia, MATLAB or HPC environments.
