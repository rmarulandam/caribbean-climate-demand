# Claim provenance

Quantitative: claim/figure/table → generation script → machine-readable result → RUN-ID
→ analysis commit → specification version → data release → transformation pipeline → source data.
Conceptual: manuscript claim → research decision → evidence/literature/result → proposal history.
The proposal cannot prove its own claims.

Use [claim template](templates/claim.yml). Record locators, units, uncertainty, scope and
limitations. Distinguish fact, proposal assumption, hypothesis, estimate, model result,
interpretation, speculation and reviewer judgment. Verify citation metadata and the
supporting passage before use; unverified sources remain visibly unverified.
