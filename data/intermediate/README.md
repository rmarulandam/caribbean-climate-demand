# Intermediate Data Products (Zone 2)

This directory houses the intermediate filtered, regionalized, and econometrically cleaned Parquet datasets generated by the processing pipeline in `src/data/`.

---

## 1. Storage & Collaboration Architecture (Single Source of Truth)

To eliminate repository bloat, respect GitHub Git LFS bandwidth quotas (10 GB/month team cap), and avoid "two sources of truth" synchronization conflicts among collaborators, **all intermediate `.parquet` files are hosted centrally in Google Drive**.

| Component | Storage Medium | Git Tracking Policy | Purpose |
| :--- | :--- | :--- | :--- |
| **Intermediate Parquets** | **Google Drive** (`caribbean-climate-demand-data/03_intermediate/`) | **Ignored in `.gitignore`** | Heavy multi-gigabyte extracts and cleaned microdata panels. |
| **Audit Ledgers & Metadata** | **Git Standard** (`data/intermediate/sui_caribe_f2_attrition.json`) | **Tracked in Git** | Step-by-step attrition metrics, schema checks, and integrity logs. |
| **Pipeline Scripts** | **Git Standard** (`src/data/*.py`) | **Tracked in Git** | Deterministic, reproducible code to rebuild intermediate data from raw sources. |

> [!IMPORTANT]
> **Collaborator Workflow:**
> 1. **To download:** Download the desired `.parquet` file from `caribbean-climate-demand-data/03_intermediate/` directly into your local `data/intermediate/` folder.
> 2. **To generate locally:** Run the corresponding script in `src/data/` (e.g., `python src/data/02_filter_caribe_sui_historic.py`).
> 3. **To share updates:** Upload new/updated `.parquet` products to `03_intermediate/` on Google Drive. Never force-add `.parquet` files to Git.

## 4. Integrity Verification

All scripts output SHA-256 checksums upon completion. Before running estimation or downstream merges, you can verify file integrity using:

```bash
# Windows PowerShell
Get-FileHash data/intermediate/sui_caribe_f2_clean.parquet -Algorithm SHA256

# Linux / macOS
sha256sum data/intermediate/sui_caribe_f2_clean.parquet
```
