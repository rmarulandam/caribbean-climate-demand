# CREG Tariffs & DANE Macroeconomic Series

This directory is managed directly in the repository via **Git LFS** (tracking rule: `data/tariffs/*.xlsx`, `data/tariffs/*.csv`).

## Files in this directory:
1. `CREG_CU_Tarifas_2021_2024.xlsx`: Monthly published Unit Cost of Service ($CU$, $\$ / \text{kWh}$) broken down by components ($G, T, D, C, P, R$) for **Afinia** and **Air-e** across voltage level 1 residential markets.
2. `dane_ipc_2021_2024.csv`: Monthly Consumer Price Index (IPC) published by DANE, re-indexed to base December 2023 = 100 for calculating real electricity expenditures.
